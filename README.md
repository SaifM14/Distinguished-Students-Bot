# Distinguished-Students-Bot
🤖 حول بوت طلاب المتميزين

بوت طلاب المتميزين هو مشروع تعليمي يهدف إلى خدمة جميع طلبة مدارس المتميزين في العراق، وتسهيل وصولهم إلى المصادر والمعلومات والموارد الدراسية التي يحتاجونها خلال مسيرتهم التعليمية.

👨🏻💻 عن المؤسس
طالب طب ومالك بوت طلاب المتميزين، لم يكن الهدف من المشروع مجرد إنشاء بوت، بل بناء مساحة تعليمية تساعد الطلبة على الوصول إلى ما يحتاجونه بصورة أسهل وأكثر تنظيماً.

🤍 كل ما يحتاجه الطالب، في مكان واحد.
